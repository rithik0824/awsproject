AWS Systems Manager (SSM) Integration

This portal utilizes AWS Systems Manager Parameter Store to inject centralized configurations securely into running instances without hardcoded secrets or redeploying code.

Loading configuration...

AWS SSM Capabilities in this Project:

  • SSM Parameter Store: Dynamically loads hospital parameters (/hospital-portal/*).
  • SSM Session Manager: Connect securely to EC2 terminal with aws ssm start-session without opening port 22 or managing SSH keys.
  • SSM Run Command: Trigger remote configuration updates and container deployments via GitHub Actions.
